# Power-BI-AdventureWorks-Sales-Customer_Anlysis
This dashboard was created as a project for a Udemy course. The exercise uses the free 'AdventureWorks' sample database provided by Microsoft to gain insights into sales, products, and customers.

Udemy Course: Master Power BI Desktop for data prep, data analysis, data visualization & dashboard design w/ top Power BI instructors!

The project focuses on practicing Power BI functionalities: importing, cleaning, and shaping data; creating measures; and visualizing data (periodic sales, insights into individual products, and consumer characteristics).
